# Lesson 1: Getting Started with MeeChain

## 🎯 เป้าหมาย

ในบทเรียนนี้คุณจะได้เรียนรู้:
- MeeChain คืออะไรและทำงานอย่างไร
- วิธีการสร้างบัญชีและเชื่อมต่อ wallet
- การทำ quest แรกของคุณให้สำเร็จ
- การใช้งาน MeeBot ผู้ช่วยอัจฉริยะ

## 📖 MeeChain คืออะไร?

MeeChain เป็นแพลตฟอร์มติดตามเป้าหมายและภารกิจที่ผสานเทคโนโลยี:

- **AI (MeeBot)**: ผู้ช่วยอัจฉริยะที่มีอารมณ์และบุคลิกภาพ
- **Web3**: ใช้ blockchain เพื่อความโปร่งใสและปลอดภัย
- **Gamification**: ระบบ badge, quest, และรางวัล

## 🚀 ขั้นตอนการเริ่มต้น

### 1. สร้างบัญชี

1. ไปที่ [app.meechain.io](https://app.meechain.io)
2. คลิกปุ่ม "Get Started"
3. กรอกข้อมูลพื้นฐาน

### 2. เชื่อมต่อ Wallet

MeeChain รองรับ wallets ต่างๆ:
- MetaMask
- WalletConnect
- Coinbase Wallet

**ขั้นตอน:**
1. คลิก "Connect Wallet"
2. เลือก wallet ที่ต้องการ
3. อนุมัติการเชื่อมต่อ
4. เลือก network (Polygon)

### 3. รู้จัก MeeBot

MeeBot จะทักทายคุณด้วยข้อความ:
> "สวัสดีครับ! ยินดีต้อนรับสู่ฐาน MeeChain ครับ! 💙"

MeeBot จะคอย:
- ให้กำลังใจเมื่อคุณทำ quest
- แนะนำเมื่อคุณติดปัญหา
- ฉลองความสำเร็จร่วมกับคุณ

## 🎮 Quest แรกของคุณ

### Quest: "First Steps"

**เป้าหมาย:**
- เชื่อมต่อ wallet ✓
- กรอกข้อมูลโปรไฟล์
- อ่านบทเรียนนี้

**รางวัล:**
- 100 points
- 10 MEE tokens
- Badge "First Quest" 🎯

### วิธีทำ Quest

1. ไปที่หน้า "Quests"
2. เลือก "First Steps"
3. ทำตามขั้นตอนที่ระบุ
4. คลิก "Claim Reward" เมื่อสำเร็จ

## 💡 เคล็ดลับ

- MeeBot จะคอยช่วยเหลือตลอดเวลา
- ทำ quest ทุกวันเพื่อรักษา streak
- เชื่อมต่อกับชุมชนเพื่อเรียนรู้เพิ่มเติม
